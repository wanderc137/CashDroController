# Rec · CashDroController

Video asciinema del ciclo de cobro y del patrón de pago con Solana Pay.

- `cashdro-solana.cast`: grabación asciicast v2 original (100×30).
- `cashdro-solana.cast.js`: la misma grabación embebida como `window.CASHDRO_CAST` para la página.

El reproductor vive en `../assets/cashdro-video.js` y se usa en la sección `#video` de `docs/index.html`.

Reproducir localmente:

```bash
asciinema play cashdro-solana.cast
```
